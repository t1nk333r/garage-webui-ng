# Screenshots

These are the images in the project README. They were captured at a 1440x900
viewport with a device scale factor of 2, which gives 2880x1800 PNGs, in the
default Dark Pastel theme. `dashboard-light.png` and `browse-light.png` use the
Pastel theme. `directory-listing.png` shows a generated directory listing page
and is smaller, at 2200x800.

The data is made up. It comes from a throwaway three-node Garage cluster in
Docker with sample buckets, keys and files. No password field holds a value.
