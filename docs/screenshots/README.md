# Screenshots

The images in the project README. Captured at a 1440x900 viewport with a 2x
device scale factor (2880x1800 PNGs), in the default Dark Pastel theme;
`dashboard-light.png` and `browse-light.png` use Pastel.

The data is made up: a throwaway three-node Garage cluster in Docker with
sample buckets, keys and files. No password field holds a value.
